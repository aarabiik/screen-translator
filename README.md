# Google Screen Translator (In-Place HUD) 🚀

Легковесное приложение для мгновенного перевода текста прямо на экране компьютера поверх оригинальных слов в режиме реального времени.

## ✨ Особенности
- **In-Place перевод поверх слов**: плашки с переводом накладываются прямо на место оригинального текста.
- **Прозрачность для кликов (`WindowTransparentForInput`)**: перевод не мешает кликать сквозь него в браузере, программах или играх.
- **Мгновенный OCR**: аппаратное распознавание через системный Windows Media OCR без задержек.
- **Google Translate**: качественный и связный перевод через движок Google Translate с автокэшированием фраз.
- **0% нагрузки на систему**: в режиме ожидания приложение спит и вообще не расходует процессор (0.0% CPU).
- **Фоновый режим и трей**: работает тихо через `pythonw`, доступна иконка в системном трее Windows.

---

## ⌨️ Горячие клавиши
- **`Alt + Q`** (или **`Ctrl + Shift + T`**) — выделить область на экране для перевода.
- **`Esc`** — мгновенно убрать все плашки перевода с экрана.
- **Правый клик мыши** — отменить выделение области.

---

## 🛠️ Установка и запуск

### Требования
- Windows 10 / 11
- Python 3.10+

### Установка зависимостей
```bash
pip install PyQt6 winocr keyboard pillow
```

### Запуск
- Для обычного запуска: запустите `run.bat`
- Для бесшумного запуска в фоне (без консоли): запустите `run_silent.bat`
